# Capstone — Agentic RAG Knowledge Assistant

This is the integration project to build after Phases 2–4. It is intentionally a starter, not a claim that the full application is already implemented.

## Planned architecture
1. Ingestion: load files and preserve metadata.
2. Retrieval: hybrid search, reranking and citations.
3. Agent: choose retrieval/tools under controlled rules.
4. Evaluation: golden questions and retrieval/answer metrics.
5. API: FastAPI request/response layer.
6. Security: environment secrets, validation, access checks.
7. Operations: logs, tracing, health checks and Docker.

Start by implementing one layer at a time. Keep tests for each layer.
