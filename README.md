# Advanced RAG Engineering Lab

A hands-on Python learning and engineering workspace focused on
Generative AI, Retrieval-Augmented Generation (RAG), and AI engineering.

## Topics covered

- Document ingestion: TXT, CSV, HTML, PDF and DOCX
- Document metadata and loaders
- Text chunking strategies
- Embeddings and semantic similarity
- Vector databases and ChromaDB
- BM25 and keyword retrieval
- Vector and hybrid search
- Reciprocal Rank Fusion (RRF)
- Retrieval-Augmented Generation
- Production RAG concepts
- Google Gemini API and Python integration

## Technology stack

- Python
- LangChain
- Google Gemini
- Hugging Face
- ChromaDB
- FastAPI

## Project structure

The workspace contains practical projects, scripts, datasets and
learning exercises. Refer to individual project folders for instructions.

## Setup

1. Clone this repository.
2. Create a virtual environment.
3. Install the required dependencies.
4. Configure your own API keys in a local .env file.
5. Run the relevant Python project scripts.

## Security

API keys, environment files, virtual environments and generated
database files are excluded from this repository.

## Learning purpose

This repository documents practical learning and experimentation
in Generative AI and RAG engineering.
